# be-hands-on-set3

Meeting room booking backend service built with Java 21, Spring Boot 3.4.3, Spring Data JPA, and H2 in-memory database.

## Prerequisites
- Java 21+
- Maven Wrapper (`./mvnw`)

## Running the Application
```bash
./mvnw spring-boot:run
```

## Running Tests
```bash
./mvnw test
```
